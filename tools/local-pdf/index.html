    Results

      01 Read in memory only

      Your files are opened with the browser’s own file API and parsed in this tab. No network request is made, so no copy exists on a server, a log or a CDN.

      02 Rebuilt page by page

      Each page is copied into a brand-new document and written out here. Your original files are never modified.

      03 The result is measured

      The file we hand back is re-opened in this tab and its real page count read out — the number you see is measured, not assumed.

      Notes. Bookmarks, links, form fields and digital signatures may not survive a rebuild — signed documents lose their signature. Password-protected PDFs must be unlocked first. Very large files are limited by your device’s memory.
