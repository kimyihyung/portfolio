      How it works

      1. Paste a link. The mode is detected — direct file, HLS playlist, or a page that needs the Worker.
      2. Analyze. For HLS you get the variants with resolution and bitrate; for a page you get the formats the Worker found.
      3. Pick one and download. The progress bar shows bytes as they arrive; Cancel stops the transfer immediately and keeps nothing.
      4. Keep the file. It is written from a Blob in this tab — the browser's own download, straight to your folder.
      Rights are not included. Save what you own, what you are licensed to keep, or what is published for download. Many platforms forbid saving their streams in their terms, and a tool does not change that.
      Very large VODs are heavy in a tab. An hour of 1080p can be 1–3 GB held in memory before it is written. On a phone, prefer a shorter clip or a lower variant — the size is shown as it grows.

      Questions

      Does anything get uploaded?

      No. Downloads only ever read. The finished file is assembled as a Blob in this tab and handed to the browser's own save dialog. There is no account, no analytics and no font or library pulled from a CDN — the only optional server is the Worker you deploy yourself.

      Which links work without a Worker?

      Any direct file link, and any HLS playlist whose host allows cross-origin reads. If a playlist or file refuses the request (CORS), the status line says so — tick Fetch through the Worker and the same URL is fetched by your Worker instead.

      Why does YouTube need the Worker at all?

      A page cannot read youtube.com or the media hosts behind it — the browser blocks the cross-origin request and YouTube refuses datacenter traffic from a plain fetch. Your Worker asks for the player response with a mobile client, keeps the stream address, and passes the bytes through. It stores nothing: no KV, no R2, no database, no console output.

      A YouTube download stops at 0% or says “not available”.

      Two common causes. First, YouTube sometimes answers a Worker IP with a bot check (“Sign in to confirm you're not a bot”) — nothing to fix in the page; a retry minutes later or a different video usually works. Second, stream addresses expire within a few hours: analyze again rather than reusing an old tab.

      Can I get 1080p with sound in one file?

      YouTube serves 1080p and above as separate video and audio streams. This page saves each one cleanly; to put them together, run one command on a desktop: ffmpeg -i video.mp4 -i audio.m4a -c copy out.mp4. Progressive formats (usually 360p/720p) already carry both tracks and need no step.

      What is kept in my browser?

      One key: kyh.lang, the EN/KO choice you picked. No history of links, no tokens, no Worker address — the address is either compiled into the page or typed into this tab's memory for the session.

      Does an iPhone download a Blob?

      Safari in iOS 13 and later saves it, opening the share sheet or the Files picker. Very large files can be refused by iOS memory limits, so on a phone keep files to a few hundred megabytes; a desktop handles the rest.
