The file is opened by this page with a local object URL, decoded by the browser's own video decoder, drawn into a canvas, and compressed here in JavaScript. The counter in the footer reports every request this page makes outside its own origin; it stays at zero.

Why the GIF is heavy

A GIF keeps every frame almost on its own and caps a palette at 256 colours, so size grows with width × height × frames. Dropping to 480 px and 10 fps, or to 64 colours, is usually enough to bring a short clip down to a couple of megabytes.

Palette and dithering

Median cut samples the clip, then splits the colour space into the palette you asked for, so a single palette serves every frame and colour stays steady. Floyd–Steinberg spreads the rounding error of each pixel into its neighbours — smoother gradients, more noise, a slightly bigger file.

Questions

Which formats can be opened?

Whatever the browser decodes: MP4 with H.264 everywhere, WebM in Chrome and Firefox, and MOV when its codec is supported. Safari on an iPhone does not decode WebM, and Chrome on Windows often cannot decode the HEVC inside an iPhone MOV — convert those first or use a desktop browser.

Why only 15 seconds?

Because the whole clip is held in memory as pixels while it is encoded: 15 seconds at 640 px and 20 fps is already around 130 MB of frames, and a phone tab will not thank you. Short loops are also what GIF is good at.

Can the GIF be transparent?

No. GIF transparency is a single on/off bit per pixel, which looks ragged on moving footage, so the frames are composited as they are. If the clip has an alpha channel it is flattened onto black.

Note. Only convert clips you have the right to use. The page never modifies your file and never sends it anywhere — the GIF is a new file you download.

No third-party library: decoding uses the browser's video element, and the median-cut quantiser, the Floyd–Steinberg dither, the LZW compressor and the GIF89a container are all written into this page. Everything is served from this site with the page, never from a CDN.
