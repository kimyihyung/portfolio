Where the watermark is drawn

Each export re-draws the mark on a canvas the size of the original, so nothing is scaled down on the way out. The size is a share of the image width, which is why a 4000-pixel photo and a 600-pixel screenshot get a mark of the same visual weight.

One mark or a tile

One mark puts a single stamp at the anchor you pick, offset by the margin. Tile repeats it across the whole frame on a diagonal grid — the version that survives a crop, at the cost of looking like a stock preview.

The shadow is not decoration

White text vanishes on a white shirt and black text vanishes on a dark wall. The shadow draws the same string behind itself in translucent black, which keeps the mark legible over almost any photo without a solid plate.

What leaves the file

Every export is encoded again by the browser, so EXIF, GPS coordinates, the camera model and the capture time do not come along. Keep the original if you still need that data — the copy here is the one meant for posting.

Questions that come up

Are my photos uploaded anywhere?

No. Files are read with the browser's own file API, drawn on a canvas and encoded again inside the tab. The page makes no network request at all, so no image, filename or watermark string leaves the device.

Does the export keep the original resolution?

Yes. The canvas is created at the source pixel size and only the encoding changes, so a 4000×3000 photo comes back at 4000×3000 with the mark on it.

Why does the ZIP come out without compression?

JPEG and WebP are already compressed, so a second pass mostly costs time. The archive is written store-only in the tab — one file to download instead of twenty.
