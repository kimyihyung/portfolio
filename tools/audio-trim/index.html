Nothing leaves the tab

The file is opened by this page, decoded with the browser's own audio decoder, and encoded back to WAV in JavaScript. The counter in the footer reports every request this page makes outside its own origin; it stays at zero.

What the WAV keeps

The export is uncompressed 16-bit PCM at the rate the browser decoded at — usually 44.1 or 48 kHz. That is a lossless copy of the decoded audio, and roughly 10 MB per minute in stereo.

Cuts that do not click

Zero-crossing snap keeps both edges at points where the waveform is already at silence, and a fade of 20–50 ms covers the rest. For a looping clip, set a fade out of 0 and cut exactly on the beat.

Questions

Does it work on a phone?

Yes. The waveform responds to touch, and the file picker opens the phone's own files. Safari decodes MP3, WAV, M4A and AAC but not OGG or FLAC, so those two need Chrome, Firefox or a desktop.

How long a file can it open?

The limit is the memory of the tab, not a counter: a one-hour stereo file decoded at 48 kHz takes about 1.4 GB, which most phones will refuse. Under about 30 minutes works on a normal laptop; for a full podcast, cut it in pieces.

Can I export MP3 instead?

Not from this page — an MP3 encoder is a sizeable library and would have to be shipped with the page. WAV needs no encoder, so the tool stays small and the output is exact. Convert the WAV afterwards if you need a smaller file.

Note. Only trim audio you have the right to use. A browser tab can be reloaded by accident, so keep the original file where it is — the export is a new file and the source is never modified.

No third-party audio library: decoding uses the Web Audio API and the WAV writer is part of this page. Everything is served from this site with the page, never from a CDN.
