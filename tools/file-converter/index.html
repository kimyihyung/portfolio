                      Results

                        01Read straight into memory

                        Files are opened with the browser’s own file API and decoded in this tab. No request leaves the page — not to a server, not to a CDN. Every library this tool uses is served from the same folder as this page.

                        02Converted, then measured

                        Each result is re-opened before you get it: images by decoding them again, PDFs by counting their pages. The size and page count shown are read from the actual output, not assumed.

                        03Released when you are done

                        Outputs live in a blob URL that is revoked when you clear the list or close the tab. Nothing is written to storage, and metadata such as EXIF and GPS is dropped by re-encoding.

                        Limits. Browser encoding is not always the smallest: a PNG photo can come out larger than its JPEG. Very large PDFs and 600 DPI renders are capped by device memory. Password-protected PDFs must be unlocked first. Print → PDF opens your browser’s print dialog and needs system Korean fonts for Korean text.
