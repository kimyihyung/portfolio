    How it works

    Three things worth knowing

    01 The save is a new file, not an edit

    EXIF, GPS, IPTC and XMP sit in header blocks beside the pixels. RedacSnap draws the pixels onto a canvas and encodes a brand-new file from them, so those blocks have nowhere to be copied from. The panel on the right shows what the original carried and what the saved bytes actually contain.

    02 Blur is for looks, black is for keeps

    A mosaic or blur makes a face unreadable at a glance, which is enough for a street photo. For a card number, a document or an address, use the black bar: a strong blur can sometimes be attacked statistically, a filled rectangle cannot.

    03 Nothing is left behind

    No upload, no account, no cookie, no external script. Close the tab and the pixels are gone from memory — the only copy is the file you chose to save. The counters in the header and footer read from the page's own network activity.

    Questions

    Straight answers
    Does the photo get uploaded anywhere?
    No. The file is decoded by the browser's own image decoder and drawn into a canvas in this tab. The page has no endpoint to upload to — the counter in the header and the footer read the page's own network activity and stay at zero.
    How does the EXIF and GPS data actually disappear?
    The export is not the original with fields deleted — it is a new file built from canvas pixels alone. After you press Download, RedacSnap reads the bytes it just produced and counts the metadata fields it finds: zero, and that count is what the panel reports.
    Is mosaic or blur safe enough?
    For a face in a crowd, usually yes. For a passport, a bank card, a licence plate or a screen full of text, no — use the black bar. Compression artefacts and repeated content can sometimes let a blur be reconstructed, while a solid fill carries no information at all.
    Which format should I save in?
    JPEG at quality 0.9 for photos you post or send. PNG for screenshots and documents where text must stay sharp. WebP when you want the smallest file for the same quality. None of the three carries the original metadata through this tool.
