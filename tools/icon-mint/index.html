    Questions
    
        favicon · PWA
      
    
      
    
        
    
          Which files do I actually need?
          
    For a normal website: favicon.ico at the root, favicon-32x32.png and favicon-16x16.png beside it, apple-touch-icon.png for iOS home screens, and the head snippet. Add site.webmanifest with the 192 and 512 PNGs when the site should install as a PWA. All eight files can sit together in the site root.
    
        
    
        
    
          Is the image uploaded anywhere?
          
    No. The file is read with the browser's File API, drawn on a canvas in this tab, and the PNG, ICO and ZIP bytes are assembled in memory. The counters on this page read its own network activity — and there is no endpoint to send an image to.
    
        
    
        
    
          Why does my transparent logo look flat?
          
    A transparent logo on a transparent icon disappears into dark browser tabs. Set a background colour, or keep transparency and add 10–20% padding so the mark survives at 16 pixels. iOS composites apple-touch-icons on black when they have no background, so pick a colour that reads on both.
    
        
    
        
    
          What makes an icon acceptable for an installable PWA?
          
    The manifest needs a 192×192 and a 512×512 PNG. For a maskable icon the artwork must sit inside the central safe zone, so keep padding at 20% or more if the 512 PNG is also declared maskable. This pack ships the 512 PNG with the padding you chose — raise it before downloading if you plan to use purpose: maskable.
