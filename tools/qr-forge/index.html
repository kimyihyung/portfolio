01 Opened, never uploaded

      
The image you drop is turned into canvas pixels in memory, decoded, and dropped again. There is no endpoint for it to be sent to, and the counter at the bottom of this page reports every request this page makes.

    

    

      
02 A real QR code

      
Output follows ISO/IEC 18004: byte mode, the smallest version from 1 to 40 that fits, automatic mask selection and error correction from L to H. The quiet zone and the two colours are printed into the file itself.

    

    

      
03 A decoder that stays local

      
Decoding uses jsQR, served from this site with the page rather than from a CDN, over pixels from your own file. Several scales and both normal and inverted pixel grids are tried before giving up.

    

  


  
Questions

  

    

      
Does the code or the image leave my device?

      
No. Both directions are JavaScript in this tab. The footer counts this page's network requests, so you can see that nothing outside this site is contacted.

    

    

      
What settings matter when I print it?

      
Keep the quiet zone at four modules or more, keep the foreground darker than the background, and use M for a balanced code or Q/H where the print may smudge or be partly covered. Under about 2 cm of printed width, phone cameras start to struggle.

    

    

      
Is a Wi-Fi code safe to hand out?

      
The code carries the password in plain text, because that is how a phone joins without typing it. Anyone who scans it gets the network — hand it out the way you would hand out the password, and change it if the code travels too far.

    

    

      
Why does an image sometimes fail to read?

      
Small, cropped, blurred, angled or glared photos are the usual causes. The decoder tries several sizes and inverted pixels too, but a sharper original — whole code in frame, in focus — is what makes it work.

    

  


  
Note. A QR code is a picture of data, not a link that can be checked: scan a code from someone else before you trust what it opens. When in doubt about a printed code, print a test copy and read it with your own phone first.
