## 검색·공유(SEO)

- `robots.txt`, `sitemap.xml` — 색인용. 사이트맵에 실제 존재하는 9개 URL만 수록합니다.
- 페이지별 `og:title`·`og:description`·`og:url`·`og:image`, `twitter:card`, `rel="canonical"`
- 공유 카드 이미지 1200×630은 `assets/img/og/*.jpg`. 문구를 고칠 때는 카드도 함께 다시 만들어야 합니다.
- 루트 `index.html`에는 Person·WebSite 구조화 데이터(JSON-LD)가 들어 있습니다.
